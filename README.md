## ðŸš€ Getting Started

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.17 or later)
- [MongoDB](https://www.mongodb.com/) instance (local or MongoDB Atlas connection string)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AaryarajPatil/Puzzle-Pie-Web-Game-for-People-with-Dyscalculia-Disorder.git
   cd Puzzle-Pie-Web-Game-for-People-with-Dyscalculia-Disorder
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory and add your MongoDB connection string:
   ```env
   MONGO_URI=your_mongodb_connection_uri
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the app.
